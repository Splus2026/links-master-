# Загрузчик файлов по списку ссылок

Программа скачивает книги и тексты по списку ссылок
из `links.ini`, раскладывает их по папкам разделов, распаковывает архивы и
преобразует DOC в DOCX. Всё, что не удалось скачать автоматически, собирается
на одной HTML-странице для ручной загрузки.

## Возможности

- выбор баз галочками; кнопка «Ссылки для загрузки» открывает `links.ini`,
  после сохранения файла список обновляется сам;
- ветки форума teros.org.ru: все страницы, тексты сообщений → один TXT;
- «Грани Агни Йоги» (bn-abramov.ru): весь текст страницы → `Г50.txt` и т.д.;
- страницы newzapovedrussia.ru: поиск кнопки OneDrive и загрузка файла;
- документы VK, royallib и другие сайты: если вместо файла пришла страница,
  ссылка на файл ищется на ней;
- папки Google Диска (через `gdown`);
- распаковка ZIP (с русскими именами), RAR и 7Z (нужен 7-Zip или WinRAR),
  по желанию — удаление архива после успешной распаковки;
- DOC → DOCX через Microsoft Word (`pywin32`) или LibreOffice;
- пропуск уже скачанного, лог `downloads/загрузка.log`, таймер загрузки.

## Установка и запуск (Windows)

```
pip install -r requirements.txt
start.bat
```

Результаты — в папке `downloads` рядом с программой:
`downloads/<раздел>/…`, страница `downloads/ручная_загрузка.html`.

## Формат links.ini

```
Название базы
https://ссылка-1
https://ссылка-2

Следующая база
https://ссылка
```

Строки, начинающиеся с `#` или `;`, пропускаются.

## Состав

| Файл | Назначение |
|---|---|
| `links_loader.py` | окно программы (Tkinter) |
| `loader/ini_parser.py` | чтение `links.ini` |
| `loader/sources.py` | обработчики сайтов |
| `loader/http_utils.py` | загрузка страниц и файлов |
| `loader/postprocess.py` | распаковка и DOC → DOCX |
| `loader/report.py` | страница ручной загрузки |
| `loader/common.py` | общие функции |
